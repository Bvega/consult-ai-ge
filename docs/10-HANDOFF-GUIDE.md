## Success Criteria by Week

### Week 1
- [ ] Bubble workspace set up
- [ ] 8 tables created
- [ ] Auth works (signup/login/reset)
- [ ] Profiles created + saved
- [ ] 0 critical bugs
- **Gate:** GO to Week 2?

### Week 2
- [ ] Search returns correct results
- [ ] Matching algorithm correct
- [ ] Messaging works
- [ ] Request consultation end-to-end
- **Gate:** GO to Week 3?

### Week 3
- [ ] Subscriptions work (Stripe test)
- [ ] Bookings + payments work
- [ ] Payouts calculate correctly
- [ ] Ratings update consultant average
- **Gate:** GO to Week 4?

### Week 4
- [ ] Admin dashboard works
- [ ] Mobile responsive
- [ ] All edge cases handled
- [ ] Bolivar UAT complete
- **Gate:** 🚀 LAUNCH

## Escalation Path
- Requirements unclear: GitHub Issues @Bvega (24hr response)
- Technical blocker: Bubble forums, then escalate
- Timeline risk: Alert ASAP (2+ days warning)
